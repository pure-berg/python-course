# Неделя 4. Продвинутый Python + алгоритмы

**Цель недели:** уверенно владеть итераторами, генераторами, декораторами, контекстными менеджерами; решать задачи уровня LeetCode Easy и понимать сложность O(n).

Это ровно то, что спрашивают на техническом собеседовании по Python.

## План по дням

### День 1 — итераторы и генераторы
- [ ] Протокол итератора: `__iter__`, `__next__`, `StopIteration`. Что на самом деле делает `for`.
- [ ] Генераторы: `yield`, `yield from`, генераторные выражения `(x for x in ...)`. Ленивость и экономия памяти.
- [ ] Задачи `fib`, `chunked`, `Countdown` в [week04.py](week04.py).

### День 2 — декораторы и контекстные менеджеры
- [ ] Декоратор с `functools.wraps`, декоратор с параметрами (`@retry(times=3)`).
- [ ] Контекстный менеджер: класс с `__enter__/__exit__` и `@contextlib.contextmanager`.
- [ ] Задачи `count_calls`, `memoize`, `suppress`.

### День 3 — стандартная библиотека
- [ ] `collections`: `Counter`, `defaultdict`, `deque`, `namedtuple`, `OrderedDict`.
- [ ] `itertools`: `chain`, `groupby`, `product`, `permutations`, `combinations`, `islice`.
- [ ] `functools`: `lru_cache`, `partial`, `reduce`.
- [ ] Перерешай 3 задачи недели 1 через `Counter`/`defaultdict` — станет короче.

### День 4 — сложность алгоритмов и структуры данных
- [ ] Big-O: O(1), O(log n), O(n), O(n log n), O(n²). Сложность операций `list`, `dict`, `set`, `deque`.
- [ ] Почему `dict`/`set` — хеш-таблицы и что это даёт.
- [ ] Бинарный поиск, два указателя, скользящее окно, стек.
- [ ] Задачи `binary_search`, `two_sum`, `valid_brackets`, `merge_sorted`.
- [ ] Книга для фона (лёгкая): А. Бхаргава «Грокаем алгоритмы».

### День 5 — алгоритмы, продолжение
- [ ] Задачи `group_anagrams`, `top_k_frequent`, `max_subarray`, `rle_encode`, `longest_unique_substring`.
- [ ] Рекурсия и её стоимость; когда превращать в цикл.

### День 6 — LeetCode
- [ ] Зарегистрируйся на [LeetCode](https://leetcode.com/) и реши 5 задач Easy из списка [NeetCode 150](https://neetcode.io/practice) (разделы Arrays & Hashing, Two Pointers, Stack).
