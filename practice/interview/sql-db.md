# SQL и базы данных

- ⭐ `INNER`, `LEFT`, `RIGHT`, `FULL`, `CROSS JOIN` — разница, нарисовать.
- ⭐ `WHERE` vs `HAVING`. Порядок выполнения частей `SELECT` (FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT).
- ⭐ Агрегатные функции и `GROUP BY`. `COUNT(*)` vs `COUNT(column)`.
- ⭐ Индексы: что это, B-tree, когда индекс не используется, минусы индексов. Составной индекс и порядок колонок.
- ⭐ Транзакции, ACID.
- Уровни изоляции транзакций и аномалии (грязное чтение, неповторяемое чтение, фантомы) — обзорно.
- ⭐ Первичный и внешний ключ. `ON DELETE CASCADE`.
- Нормализация: 1НФ, 2НФ, 3НФ. Когда денормализуют.
- Оконные функции: `ROW_NUMBER`, `RANK`, `DENSE_RANK`, `LAG/LEAD`, `SUM() OVER`.
- Подзапрос vs CTE vs JOIN.
- `UNION` vs `UNION ALL`.
- `DELETE` vs `TRUNCATE` vs `DROP`.
- ⭐ SQL-инъекция и защита.
- ⭐ ORM: плюсы/минусы. Проблема N+1 и как её решать (в SQLAlchemy — `selectinload`/`joinedload`).
- Миграции: зачем, как работает Alembic.
- SQL vs NoSQL: когда что (Redis, MongoDB — обзорно).
- `EXPLAIN` / `EXPLAIN ANALYZE`.
