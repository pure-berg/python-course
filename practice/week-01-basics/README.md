# Неделя 1. Инструменты и база Python

**Цель недели:** уверенно писать небольшие программы на строках, списках и словарях; работать в терминале и с git каждый день.

**Нагрузка:** ~5 ч/день, 6 дней + 1 день отдыха/повторения.

## План по дням

### День 1 — рабочее место
- [ ] Открой этот репозиторий в Codespaces (см. [README практики](../README.md)) **или** установи Python 3.12 + VS Code локально.
- [ ] Терминал: `pwd`, `ls`, `cd`, `mkdir`, `touch`, `cat`, `rm`, `mv`, `cp`, стрелка ↑, Tab. Час практики — [MIT Missing Semester, лекция 1](https://missing.csail.mit.edu/2020/course-shell/).
- [ ] Git: пройди первые уровни [Learn Git Branching](https://learngitbranching.js.org/?locale=ru_RU) (раздел «Основы»).
- [ ] Сделай первый коммит в этот репозиторий: реши первую задачу ниже, `git add`, `git commit`, `git push`.

### День 2 — типы, строки, условия
- [ ] `int`, `float`, `str`, `bool`, `None`; приведение типов; `input()`/`print()`; f-строки.
- [ ] Методы строк: `split`, `join`, `strip`, `lower`, `replace`, `startswith`, `find`, `isdigit`, `isalpha`; срезы.
- [ ] `if/elif/else`, `and/or/not`, тернарный оператор `a if cond else b`.
- [ ] Задачи 1–3 в [week01.py](week01.py).

### День 3 — циклы, списки, кортежи
- [ ] `for`, `while`, `range`, `break`, `continue`, `enumerate`, `zip`.
- [ ] Списки: индексы, срезы, `append/extend/insert/pop/remove`, `sorted` vs `.sort()`, `min/max/sum`.
- [ ] Кортежи и распаковка: `a, b = b, a`.
- [ ] Задачи 4–7.

### День 4 — словари, множества, генераторы списков
- [ ] `dict`: `get`, `items`, `keys`, `values`, `setdefault`, перебор, вложенные словари.
- [ ] `set`: уникальность, `&`, `|`, `-`, проверка `in` за O(1).
- [ ] list/dict/set comprehensions.
- [ ] Задачи 8–11.

### День 5 — функции
- [ ] `def`, `return`, аргументы по умолчанию (и почему нельзя `def f(x=[])`), именованные аргументы.
- [ ] Область видимости: локальные и глобальные переменные (и почему `global` — почти всегда плохо).
- [ ] Задачи 12–14.

### День 6 — мини-проект
Напиши `contacts.py` — консольную записную книжку (в отдельной папке `week-01-basics/contacts/`):
- меню в цикле: добавить / найти по части имени / удалить / показать все / выход;
- данные хранятся в словаре `{имя: телефон}`;
- кривой ввод (пустое имя, неизвестная команда) не роняет программу.

Закоммить и запушь. Это первый кусок кода, который не по тестам — **сам решаешь, как его устроить**.

### День 7 — отдых / добивка
Дорешай то, что не успел. Ответь себе вслух на вопросы ниже.

## Проверь себя
1. Чем изменяемые типы отличаются от неизменяемых? Примеры.
2. Почему `b = a` для списка не создаёт копию? Как сделать копию?
3. Почему поиск `x in set` быстрее, чем `x in list`?
4. Что вернёт функция без `return`?
5. Что делают `git status`, `git log`, `git diff`?
