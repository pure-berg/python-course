# Неделя 8. Подготовка к собеседованиям и поиск работы

**Цель недели:** уверенно проходить техническое собеседование на Junior Python Developer и выстроить поиск работы как ежедневный процесс.

С этой недели день устроен так:
- **1–1,5 ч** — отклики и переписка с рекрутерами (10–20 откликов в день, на каждый — короткое сопроводительное);
- **1 ч** — 1–2 задачи LeetCode / алгоритмы;
- **2 ч** — теория по вопросам ниже + повторение;
- **1 ч** — доработка проектов по замечаниям с собеседований.

## План по дням

### День 1 — Python-теория
Пройди [вопросы по Python](../interview/python.md). На каждый — ответ **вслух**, своими словами, с примером кода. Не можешь объяснить вслух — значит, не знаешь.

### День 2 — SQL, БД, веб
[Вопросы по БД и SQL](../interview/sql-db.md) и [по вебу и бэкенду](../interview/web-backend.md). Перерешай задачи недели 5 с нуля, без подсказок, за 30 минут.

### День 3 — алгоритмы и live coding
- [ ] [Алгоритмы для собеседования](../interview/algorithms.md).
- [ ] Live coding: реши 3 задачи, **проговаривая решение вслух**, с таймером 20 минут на задачу. Сначала — уточняющие вопросы и простое решение, потом оптимизация.

### День 4 — Django за день (обзорно)
Много вакансий на hh.ru требуют Django. Ты не станешь в нём экспертом за день, но должен понимать его устройство:
- [ ] [Официальный туториал Django](https://docs.djangoproject.com/en/stable/intro/tutorial01/), части 1–4: проект vs приложение, модели и ORM, миграции, админка, views, шаблоны.
- [ ] Обзорно: Django REST Framework (сериализаторы, ViewSet).
- [ ] Будь готов ответить: «Чем FastAPI отличается от Django? Когда что выбрать?»

### День 5 — системный дизайн (база для джуна) и рассказ о проектах
- [ ] Как устроен типичный веб-сервис: клиент → nginx → приложение → БД/кеш/очередь. Горизонтальное масштабирование (обзорно).
- [ ] Подготовь рассказ о проекте №2 на 3 минуты: задача → архитектура → самое сложное и как решил → что бы улучшил. Запиши на телефон, переслушай.
- [ ] Ответы на HR-вопросы: «Расскажите о себе», «Почему ушли в программирование», «Где видите себя через год», «Ваши слабые стороны», вилка зарплаты (посмотри реальные вилки джунов в своём городе на hh.ru).

### День 6 — пробные собеседования
- [ ] Минимум 1 mock-интервью с живым человеком (знакомый разработчик, сообщества в Telegram, сервисы взаимных интервью).
- [ ] Можно с ИИ: попроси провести техническое собеседование на Junior Python, задавать по одному вопросу и **не подсказывать**, в конце — разбор слабых мест.
- [ ] После каждого реального собеседования — запиши вопросы, на которые не ответил, и разбери их в тот же день. Это лучший учебный материал.

### День 7 — отдых

## После 8-й недели
Курс закончился, поиск — нет. Обычно поиск первой работы занимает от нескольких недель до нескольких месяцев. Продолжай в ритме:
отклики каждый день → собеседования → разбор ошибок → доработка проектов → LeetCode. Через месяц обнови резюме и проекты.

## Готово, если
Ответы на вопросы из `interview/` — вслух, без подсказок; есть записанный рассказ о проекте; ≥ 50 откликов; хотя бы 1 пробное собеседование.
