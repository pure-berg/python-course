# Неделя 3. ООП, типизация, первый проект в портфолио

**Цель недели:** проектировать классы, понимать наследование и «магические» методы, писать типизированный код. В конце — **проект №1 в отдельном репозитории** на твоём GitHub.

ООП спрашивают почти на каждом собеседовании джуна — эта неделя важнее, чем кажется.

## План по дням

### День 1 — классы и объекты
- [ ] Класс, объект, `__init__`, `self`, атрибуты объекта vs атрибуты класса.
- [ ] Методы: обычные, `@classmethod` (альтернативные конструкторы), `@staticmethod`.
- [ ] `@property` и сеттеры — контроль над атрибутами.
- [ ] Задачи `Temperature`, `BankAccount` в [week03.py](week03.py).

### День 2 — наследование и полиморфизм
- [ ] Наследование, `super()`, переопределение методов, `isinstance`.
- [ ] Абстрактные классы: `abc.ABC`, `@abstractmethod`.
- [ ] Композиция vs наследование («имеет» vs «является») — почему композиция чаще лучше.
- [ ] Четыре принципа ООП: инкапсуляция, наследование, полиморфизм, абстракция — **объясни каждый своими словами с примером**.
- [ ] Задача `Shape`/`Rectangle`/`Square`/`Circle`.

### День 3 — магические методы
- [ ] `__repr__`, `__str__`, `__eq__`, `__lt__`, `__hash__`, `__len__`, `__getitem__`, `__iter__`, `__contains__`, `__add__`, `__mul__`, `__bool__`.
- [ ] Почему если переопределил `__eq__`, нужно подумать о `__hash__`.
- [ ] Задачи `Vector2D`, `Stack`.

### День 4 — dataclasses и типизация
- [ ] `@dataclass`, `field(default_factory=list)`, `frozen=True`, `order=True`.
- [ ] Аннотации типов: `list[int]`, `dict[str, float]`, `X | None`, `Callable`, `TypedDict`, `Protocol` (обзорно).
- [ ] Пролистай `mypy` и `ruff` — установи `ruff` и прогони по своему коду.
- [ ] Задача `Inventory`.

### День 5–6 — проект №1: консольный трекер расходов
Создай **новый публичный репозиторий** `expense-tracker` (это уже портфолио, а не учёба).

Требования:
- классы `Expense` (dataclass: сумма, категория, дата, комментарий) и `ExpenseRepository` (хранит в JSON-файле: загрузка/сохранение);
- команды через `argparse`: `add`, `list` (фильтры `--category`, `--from`, `--to`), `delete <id>`, `stats` (сумма по категориям и по месяцам);
- валидация: отрицательная сумма, кривая дата → понятная ошибка, а не traceback;
- тесты pytest (≥ 10), включая работу с файлом через `tmp_path`;
- `README.md` проекта: что это, как установить, примеры команд, скриншот/вывод;
- `requirements.txt`, `.gitignore`, аннотации типов, `ruff` без ошибок;
- осмысленные коммиты (не «fix», «fix2», «asdf»).
