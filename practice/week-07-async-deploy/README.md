## План по дням

### День 1 — конкурентность в Python
- [ ] Процессы vs потоки vs корутины. GIL: что это и почему потоки не ускоряют CPU-задачи.
- [ ] Когда что: I/O-bound → `asyncio` или потоки; CPU-bound → `multiprocessing`.
- [ ] `asyncio`: `async def`, `await`, `asyncio.run`, `asyncio.gather`, `asyncio.Semaphore`, таймауты.
- [ ] Практика: скрипт, который асинхронно (через `httpx.AsyncClient`) скачивает 50 URL с ограничением 10 одновременных запросов, и сравни время с синхронной версией.
- [ ] Async в FastAPI: `async def` эндпоинты, почему нельзя вызывать блокирующий код внутри них.

### День 2 — Telegram-бот к проекту №2

- [ ] Токен бота — только из переменных окружения, не в коде.
- [ ] Бот — отдельный сервис в том же `docker-compose.yml`.

### День 3 — фоновые задачи и кеш (обзорно, но руками)

- [ ] Логирование в проекте: `logging` с уровнями, без `print`.
