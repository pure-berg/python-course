# Python: понимаю каждую строку

## 👉 [Открыть тренажёр: pure-berg.github.io/python-course](https://pure-berg.github.io/python-course/)

Курс для подготовки к работе **Junior Python Backend**. Ничего не нужно печатать: читаешь короткую шпаргалку, нажимаешь варианты ответов и после каждого ответа видишь объяснение. Цель — понимать любой код, включая написанный ИИ, и уметь объяснить каждую строку.

Работает в браузере на телефоне и компьютере. Прогресс сохраняется в браузере.

## Как заниматься

Один модуль в день, ~1,5–2 часа:

1. **Шпаргалка** — 5–10 минут чтения с примерами.
2. **Тест** — ~10 вопросов: «что выведет», «где баг», «что делает этот код». Модуль пройден при 80%. Ответы на все вопросы «что выведет» проверены запуском кода.
3. **Повтор ошибок** — кнопка на главной. Неверные ответы попадают туда, верный ответ убирает вопрос из списка.
4. **Задание для ИИ** — кнопка в модуле копирует промпт. Вставь его в ChatGPT или Claude: ИИ напишет код по теме и будет задавать вопросы по нему с вариантами ответа. Так тренируется чтение чужого кода.

Начни с **входного теста**: модули до первой ошибки отметятся как «можно пропустить».

## Перенос прогресса на другое устройство

Нажми на главной «Перенести прогресс» → «Скопировать ссылку» и открой ссылку на другом устройстве: прогресс загрузится туда. Ссылка переносит прогресс на момент копирования, поэтому после занятий на другом устройстве перенеси его обратно тем же способом.

## Честно о границах

Тесты учат понимать код. Но на собеседованиях джунов часто дают live coding: нужно написать код самому, пока на тебя смотрят. Для этого есть [`practice/`](practice/README.md) — задачи с автопроверкой и проекты для портфолио. Начни их, когда модули перестанут казаться трудными.
