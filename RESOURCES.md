# Бесплатные материалы

Главный принцип: **материал — вспомогательный, основное время — практика**. Не смотри по 3 курса на одну тему: выбери один источник, прочитай, сразу решай задачи.

## Python
- [Официальный туториал Python](https://docs.python.org/3/tutorial/) — первоисточник, на английском.
- [Поколение Python (Stepik)](https://stepik.org/course/58852) — бесплатный курс с сотнями задач на русском; хорош для недель 1–2, если тема не идёт.
- [CS50's Introduction to Programming with Python](https://cs50.harvard.edu/python/) — Гарвардский курс, лекции + задачи.
- [Python Tutor](https://pythontutor.com/) — визуализация выполнения кода по шагам: незаменимо, когда не понимаешь, что происходит со ссылками, рекурсией, циклами.
- [Real Python](https://realpython.com/) — статьи по любой теме, когда нужно разобраться глубже.

## Как пользоваться ИИ (ChatGPT, Claude и т.п.) во время учёбы
ИИ отлично объясняет, но легко создаёт иллюзию, что ты умеешь. Правила:
- **Можно:** «объясни, что такое замыкание, на простом примере»; «почему мой код падает с этой ошибкой — дай подсказку, но не решение»; «проведи со мной собеседование».
- **Нельзя (в учебных задачах):** «реши задачу» / копировать код, который не можешь написать сам.
- Проверка: через день перепиши решение с нуля без подсказок. Не получилось — значит, не выучил.
- В проектах портфолио ИИ использовать можно (так работают и в компаниях), но **каждую строку ты должен уметь объяснить** — на собеседовании спросят.
