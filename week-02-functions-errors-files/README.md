# Неделя 2. Функции глубже, исключения, файлы, модули, тесты

**Цель недели:** писать код, который не падает на кривых данных, работает с файлами (txt/CSV/JSON), разбит на модули и проверяется тестами.

## План по дням

### День 1 — функции как объекты
- [ ] `*args`, `**kwargs`, распаковка `f(*lst, **dct)`, keyword-only аргументы (`def f(a, *, b)`).
- [ ] Функции — объекты: передать функцию в функцию, вернуть функцию из функции. `lambda`, `map`, `filter`, `sorted(key=...)`.
- [ ] Замыкания, `nonlocal`.
- [ ] Задачи 1–4 в [week02.py](week02.py).

### День 2 — исключения
- [ ] `try/except/else/finally`, перехват конкретных исключений (а не голый `except:`), `raise`, `raise ... from ...`.
- [ ] Иерархия исключений: `Exception`, `ValueError`, `TypeError`, `KeyError`, `IndexError`, `FileNotFoundError`.
- [ ] Свои исключения: `class InsufficientFunds(Exception)`.
- [ ] Задачи 5–8.

### День 3 — файлы
- [ ] `open`, режимы `r/w/a`, `encoding="utf-8"`, `with`.
- [ ] `pathlib.Path` — вместо склеивания строк с путями.
- [ ] Модули `json` и `csv` (`DictReader`/`DictWriter`).
- [ ] Задачи 9–12.

### День 4 — модули, пакеты, окружения
- [ ] `import`, `from ... import`, `if __name__ == "__main__":`, что такое пакет и `__init__.py`.
- [ ] Виртуальное окружение: `python -m venv .venv`, `pip install`, `requirements.txt`. Почему без venv — боль.
- [ ] Стандартная библиотека: пролистай `datetime`, `random`, `os`, `sys`, `collections` (подробно — на неделе 4).
- [ ] Логирование `logging` вместо `print` для отладочных сообщений.

### День 5 — тесты сам
- [ ] `pytest`: функции `test_*`, `assert`, `pytest.raises`, фикстура `tmp_path`, `@pytest.mark.parametrize`.
- [ ] Открой `test_week02.py` и разбери, как устроены тесты, которые проверяют тебя.
- [ ] Напиши **свои** тесты к мини-проекту недели 1 (вынеси логику из `input()` в функции, чтобы её можно было тестировать).

### День 6 — мини-проект: анализатор логов
Папка `week-02-functions-errors-files/log_analyzer/`. Программа принимает путь к лог-файлу вида
```
2026-01-10 12:00:01 INFO  user=alice action=login
2026-01-10 12:00:05 ERROR user=bob action=pay msg="card declined"
```
и выводит: сколько строк каждого уровня, топ-3 пользователей по числу действий, все ERROR за указанную дату.
- запуск: `python analyzer.py logs.txt --date 2026-01-10` (аргументы — через `argparse`);
- битые строки не роняют программу, а считаются и выводятся в конце («пропущено строк: N»);
- результат можно сохранить в JSON (`--out report.json`);
- минимум 5 тестов на pytest.
