# Поиск работы

## Честно о рынке
Найти первую работу джуном сейчас сложнее, чем несколько лет назад: откликов на вакансию много, а часть простых задач забрали ИИ-инструменты.
Шансы дают не «сертификаты», а: **проекты, которые можно открыть и потрогать, уверенная база на собеседовании и количество откликов**.
Ожидай, что на одно приглашение уйдёт 10–30 откликов, а на оффер — несколько собеседований. Это нормально и не говорит о тебе ничего плохого.

## Резюме — чек-лист
- [ ] 1 страница. Должность: **Junior Python Developer** (или Junior Backend Developer).
- [ ] Блок «Навыки» — только то, о чём сможешь поговорить на собеседовании: Python, FastAPI, SQLAlchemy, PostgreSQL, SQL, Docker, docker compose, Git, pytest, asyncio, Redis, Linux, GitHub Actions, REST API, (Django — обзорно).
- [ ] Блок «Проекты» — главный для джуна. На каждый: 1 строка — что это, 2–3 пункта — что сделал **ты** и какие технологии, ссылки на GitHub и демо.
  Пример: «Сервис бронирования переговорных: REST API на FastAPI + PostgreSQL, JWT-авторизация, проверка пересечений броней, 40+ тестов (pytest, покрытие 80%), CI в GitHub Actions, деплой в Docker на VPS, Telegram-бот на aiogram».
- [ ] Прошлый опыт работы (любой) — оставь, коротко, с акцентом на то, что пригодится: ответственность, автоматизация, работа с данными.
- [ ] Образование и курсы — в конце. Незаконченный курс можно указать как «Python-разработчик (Skillbox), самостоятельное продолжение обучения».
- [ ] Ссылки: GitHub, Telegram, email. Фото — нейтральное или без фото.
- [ ] Без ошибок. Дай прочитать кому-нибудь.

## GitHub-профиль
- [ ] Профильный README (репозиторий с именем = твой ник): 3–4 строки о себе, стек, ссылки на 2–3 главных проекта.
- [ ] Закрепи (Pin) проекты №2, №1 и этот курс.
- [ ] У каждого проекта: описание, топики (теги), README по шаблону из недели 7, зелёный CI.
- [ ] Удали или сделай приватными пустые и брошенные репозитории.

## Где искать
- hh.ru — основной поток вакансий; настрой поиск «Python junior» / «стажёр Python» + удалёнка, подпишись на рассылку.
- Хабр Карьера.
- Telegram-каналы с вакансиями для джунов и Python-вакансиями (ищи по запросам «python jobs», «junior вакансии»).
- LinkedIn — если рассматриваешь зарубежные компании.
- Стажировки крупных компаний (Яндекс, Т-Банк, Сбер, Ozon, Авито, VK и др.) — у них отборы по расписанию, следи за сроками.
- Нетворкинг: знакомые разработчики, митапы, чаты сообществ. Рекомендация «изнутри» сильно повышает шансы.

## Отклики
- 10–20 в день. Не только «Junior», но и «Python-разработчик» без требований к опыту, «стажёр», «разработчик автоматизации», «backend-разработчик» с требованием опыта до 1 года.
- К каждому — 3–4 строки сопроводительного, под вакансию:
  > Здравствуйте! Откликаюсь на вакансию Junior Python Developer. Пишу бэкенд на FastAPI + PostgreSQL, вот мой основной проект: <ссылка> — сервис <что делает>, с тестами, CI и деплоем в Docker. Вижу, что у вас <что-то из вакансии> — у меня в проекте как раз <похожее>. Буду рад пообщаться.
- Тестовые задания: делай качественно, с README и тестами; после — выложи в GitHub (если не запрещено), это ещё один проект в портфолио.
