# 00. Входной тест — где ты сейчас

Цель: за **~1,5 часа** понять, с какой недели начинать и что можно пролистать.
Честность здесь важнее результата: **без ChatGPT, Google и подсказок**. Если не знаешь — так и пиши «не знаю».
Завышенный результат = ты пропустишь то, что нужно, и потом застрянешь.

## Часть 1. Вопросы (30–40 мин) → [quiz.md](quiz.md)

25 вопросов: «что выведет код» и короткие теоретические.
Ответы пиши прямо в файл (под каждым вопросом есть строка `Ответ:`), в Python **не запускай**.
Потом сверь с [answers.md](answers.md) (не открывай заранее) и посчитай баллы.

## Часть 2. Практика (45–60 мин) → [placement.py](placement.py)

8 задач от простых к сложным. Каждая — функция с описанием, внутри `raise NotImplementedError`.
Замени это на своё решение. Проверка:

```bash
pytest 00-placement-test
```

Тут можно запускать код и тесты сколько угодно — это нормально, так и работают программисты.
Нельзя только подсматривать решения.

## Итог

| Вопросы (из 25) | Практика (из 8) | Старт |
|---|---|---|
| 0–9 | 0–3 | Неделя 1 целиком, в полном темпе |
| 10–16 | 3–5 | Неделя 1 — только задачи (теорию пролистать), затем неделя 2 полностью |
| 17–21 | 5–7 | Неделя 1 пропустить (прорешать задачи за 1 вечер), начать с недели 2 |
| 22–25 | 8 | Начать с недели 3, недели 1–2 — только задачи для проверки |

Освободившиеся дни не трать на отдых — вложи их в недели 6–7 (веб и итоговый проект), там больше всего пользы для работы.
